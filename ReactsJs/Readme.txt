----------------- Setting up a React project Locally using Vite --------------------------------
To install React make sure node V 18 and above is installed. also make sure npm v 10 and 
above is also installed. You can install node by using the Node Version Manage (nvm)
by typing in the terminal "nvm install --lts" for the long-term-supported Version.

Then to install a new react project using vite you just type: 
    npm create vite@latest

it would prompt you to supply some infos such as project name, choose framework, and so on

Then when you are through
cd to the project folder
    then type npm install
        then lastly npm run dev.

from the terminal you can type code .  to lunch visual studios code in the current project folder
